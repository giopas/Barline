            Use Pocket offline

            Any browser: open Pocket once with the internet on, and from then on it opens without it, at the same address. Installing it is better: it gets its own icon and window, and the browser won't clear your songs to save space, as it may do with websites you haven't opened for a while.

            Chrome on a computer (Windows, Mac, Linux)

            Click the install icon at the right end of the address bar. Or open the ⋮ menu → Cast, save and share → Install Barline Pocket… → Install. It opens in its own window and appears with your other apps (Start menu, Launchpad or Dock).

            Edge on Windows

            Open the … menu → Apps → Install this site as an app → Install. Pin it to the Start menu or taskbar if Edge offers.

            Safari on iPhone or iPad

            Tap the Share button (the square with an arrow) → Add to Home Screen → Add. Open Pocket from that icon from now on: the songs you add there stay with the icon, not with Safari.

            Safari on a Mac

            Choose File → Add to Dock (macOS Sonoma or later). Open Pocket from the Dock from now on.

            Chrome on Android

            Open the ⋮ menu → Add to home screen (or Install app) → Install.

            Firefox

            On Android: ⋮ menu → Add to home screen. On a computer, Firefox can't install it, but Pocket still works offline in a Firefox tab once it has been opened online: bookmark it, and export your songs now and then.

            One device's Pocket doesn't share songs with another browser or another device: move them with Band → Export everything and Import a file.

            Paper chart

            Count-ins in one go

            A count-in at the start of each song, before every section change, or both. You can still change any section by hand afterwards.

            Import

            A song that's already here is merged: hints from both copies (newest wins when both changed one), nothing deleted. When the two structures differ, you choose which to keep.
